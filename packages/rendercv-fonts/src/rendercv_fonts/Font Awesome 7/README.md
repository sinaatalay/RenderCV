# Font Awesome 7.3.1

The three OTF files and `LICENSE.txt` are copied without modification from the
[official free desktop release](https://github.com/FortAwesome/Font-Awesome/releases/tag/7.3.1):
`fontawesome-free-7.3.1-desktop.zip`.

Archive SHA-256:
`c61edde261707f33376a28e9a30bb8c70c1a20bf0bd975206b809f3b3b70add5`.

These fonts support the Font Awesome 7.3.0 icon map of the `@preview/fontawesome:0.6.2`
Typst package that RenderCV imports, including the Codeberg brand glyph.
The font license is SIL OFL 1.1; see `LICENSE.txt` for the complete upstream
licensing terms.

This update incorporates the work proposed by Pierre Mesure in
[rendercv-fonts#5](https://github.com/rendercv/rendercv-fonts/pull/5) (7.2.0) and
ekeogh (`mac-eochaidh`) in
[rendercv-fonts#6](https://github.com/rendercv/rendercv-fonts/pull/6) (7.3.1).
